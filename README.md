# Carnac

> Jeu web narratif stratégie/survie en Bretagne néolithique, autour des alignements de Carnac. Comment des chasseurs-cueilleurs deviennent bâtisseurs.

**Statut :** early. Concept posé, specs MVP en cours de cadrage. Pas encore jouable.

## Concept

On incarne une habitante d'une tribu néolithique du littoral morbihannais. Boucle Sims-like préhistorique : chasse, cueillette, abri, transmission. La singularité du jeu est ailleurs.

**Progression cachée.** Les menhirs ne sont pas visibles au départ. Ils apparaissent quand la joueuse rencontre une autre tribu, quand une explication rituelle circule, quand la coopération devient possible. La construction des mégalithes devient l'objectif majeur du jeu, pas un décor.

**Le vrai sujet :** la naissance d'une civilisation. Comment on passe du campement à l'alignement de pierres sans écriture ni métal. Croyance, coopération inter-clans, évolution sociale.

## Stack

- Vite + React + TypeScript
- Three.js via `@react-three/fiber` et `@react-three/drei`
- Prototype web, cible desktop d'abord

Base d'expérience réutilisée du projet portfolio Nahual (r3f, GLB pipeline, animations, particules).
